## 💠 簡単設計

サーバーの招待リンクが送信された瞬間、**メッセージ削除・Timeout・通知**を自動実行。
設定はコマンド2つを実行するだけで完了します。

## 💠 圧倒的検知率

Discord公式の招待リンクだけでなく、**国内外17の掲示板サイトのサーバーリンク**が送信された場合も検知可能です。

| 対応リンク |
|---|
| Discord公式招待リンク (`discord.gg` / `discord.com/invite`) |
| 国内外17の掲示板・サーバーリストサイトのサーバー直リンク（詳細は下記） |

## 安心の運用方針

- Botが実行することはメッセージ削除・Timeout・通知のみ。
- 必要な権限は、「チャンネルを見る」「メッセージの送信と投稿の作成」「メンバーをタイムアウト」の3つの権限のみ。
- 検知ログはサーバーごとの設定チャンネルへリアルタイム通知

## 導入方法

1. 下記のリンクからBotをサーバーに招待
2. `/log_channel`で検知ログを送信するチャンネルを設定
3. `/timeout_duration`でタイムアウト時間（1hや3dなど）を設定。0にすることでタイムアウトをしないという選択も可能。
4. 設定完了
